## 📖 About

Vendora is a modern multi-vendor marketplace that connects buyers and vendors through a seamless commerce experience.

The platform enables buyers to discover innovative tech products while providing vendors with dedicated tools to manage products, inventory, and marketplace operations.

Built with scalability, performance, and modern web technologies in mind, Vendora demonstrates real-world marketplace architecture and role-based commerce workflows.

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/Vendora.git
cd Vendora
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

Open:

```bash
http://localhost:3000
```
